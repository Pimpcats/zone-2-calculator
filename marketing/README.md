# Zone Alert — Marketing

This branch holds everything for promoting and launching Zone Alert. It's kept separate
from the app code so you can iterate on marketing without touching builds.

## Contents
- **`ASO_STRATEGY.md`** — App Store Optimization: app name/subtitle/keyword field, conversion,
  ratings, velocity, pricing. This is your lever for "ranking higher in the store."
- **`LAUNCH_PLAN.md`** — pre‑launch, launch‑week, and post‑launch growth plan.
- **`landing/index.html`** — a ready‑to‑host promo landing page with an email‑capture form.

## How to use the landing page
1. Host it free on **GitHub Pages**, Netlify, or Vercel (it's a single static file).
2. Wire the email form to a free service (**Formspree**, Buttondown, Mailchimp) by replacing
   the `action="https://formspree.io/f/REPLACE_ME"` URL.
3. Point a custom domain at it if you want (e.g., zonealert.app).

## The honest summary of "getting to the top"
There's no switch. Ranking = **keyword relevance × conversion rate × download velocity ×
ratings.** Win a focused niche (Zone‑2 / heart‑rate training), nail the listing, get a
launch‑day download burst, and ask for reviews at happy moments. Then iterate monthly.

See `ASO_STRATEGY.md` for the concrete checklist.
